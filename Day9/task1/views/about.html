About

A small studio with a sharp process

Apexline started as a learning project for SMM Global and grew into a complete Express.js multi-page website demo — routing, static files, forms, and custom errors.

Our mission

Make web foundations easy to understand: servers, routes, assets, and UX that still feels intentional on every screen size.

How we work

Clarify the goal, sketch the page map, ship a responsive UI, then harden the edges — validation, logging, and a proper 404.

Built with the assignment stack

Node.js · Express.js · HTML5 · CSS3 · JavaScript (ES6) · dotenv · nodemon · morgan
