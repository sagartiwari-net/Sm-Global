2. Add a new row below (copy the pattern)
3. Commit & push this file too

---

## How to make a folder link

```text
https://github.com/sagartiwari-net/Sm-Global/tree/main/<PATH>
```

- Spaces in folder names → use `%20`  
  Example: `Day 1` → `Day%201`
- No spaces → use path as-is  
  Example: `Day8/task1`
