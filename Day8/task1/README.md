# SmmMynta — Day 8 Task 1 (PLP Assignment)

Educational React project: **SmmMynta** fashion store with a Product Listing Page (PLP) powered by a public API.

## Features

- SmmMynta branding (header, footer, studio, login)
- Homepage banners, mega menu, bag, wishlist, checkout, profile
- Products from DummyJSON API
- Filters, sorting, pagination (12 / page)
- Responsive + loading / error states

## Run

```bash
cd Day8/task1
npm install
npm run dev
```

## Tech

React + Vite · JavaScript · Tailwind CSS · Redux Toolkit · Axios · React Router
